第 1 章　界面总览

1.1 基本概念

名称说明
画框 (frame)每个画框内有一条灯带，对应一路灯光，共 24 路。
墙 (W1–W4)房间四面墙：W1 有 8 个画框，W2 有 4 个，W3 有 7 个，W4 有 5 个。画框编号为面向墙面从左到右依次编号，例如 W1-3 = W1 墙左数第 3 个。
三种效果 Hold：亮度保持不变。
Fade：亮度由 A 渐变到 B。
Blink：亮度在 A、B 之间来回渐变（三角波），需设置周期。
亮度范围 0–100%。每一个效果称为一“步 (step)”，每个画框最多 24 步。
Loop勾选后循环播放；未勾选则只播放一遍，并停在最后一步的亮度。
单框程序
Single frame		只控制一个画框的效果（最多 24 步），可分配给任意多个画框。
整套节目
Entire set (show)		控制全部 24 个画框的时间线，每个画框一行，各画框可在不同时间做不同的事。
新增分段节目
Cue list		整套节目的一种：时间线被分段点切成若干段 (section)。演出时由操作员按 GO，每按一次播放下一段，用于按演员提示触发灯光（见 2.8、4.4）。

两种作品相互独立：节目在 Entire set 中编辑，单框程序在 Single frame 中编辑。分段节目与普通节目在同一个 Entire set 页中制作，在节目列表中以 ⏭ 标记。

1.2 顶部栏

图 1-1　顶部栏（所有页面共有）
  1. Control / Programs　页面标签。Control：分配程序并播放；Programs：制作程序和节目。
  2. Edit / Run　模式开关。Edit：点画框用来分配程序，不会点亮灯。Run：点画框会播放该画框的程序。
  3. Simulator ▸　打开 / 关闭屏幕右侧的模拟器（虚拟房间，实时显示灯光效果）。点击后会自动切换到 Run 模式。
顶部栏及 Control 页右侧的 Find nodes、连接下拉框、Log、Nodes 面板、画框上的 ✓ 标记，以及模拟器中的 Packet loss 滑块，都属于设备通信功能，本手册不涉及，可忽略。

1.3 数据保存

所有修改自动保存在当前电脑的浏览器中。请始终使用同一个浏览器（Chrome 或 Edge），不要使用无痕窗口，也不要清除浏览器数据，否则已做的内容会丢失。建议定期在整套节目页点 Export all 导出备份（见 2.3）。

第 2 章　Programs 页 · 整套节目（Entire set）

点 Programs，再点 Entire set。这是一条类似剪辑软件的时间线：一行 = 一个画框，横向 = 时间，彩色条 = 片段 (clip)。每次修改自动保存。没有片段的空白时间，灯为熄灭状态。（Cue list 分段节目除外：空白时间保持原亮度，见 2.8。）

图 2-1　整套节目编辑页（示例：Wave around the room，依次亮起再熄灭）
  1. Entire set / Single frame　切换整套节目与单框程序（软件会记住上次的选择）。
  2. Shows　节目列表。名称后的 ↻ 表示该节目为循环节目，⏭ 表示分段节目。
  3. 节目管理按钮，见 2.3。
  4. 节目名称，可直接修改。
  5. Loop　节目循环；勾选后出现循环长度 length ... ms（见 2.6）。
  6. ▶ Play / ■ Stop　在编辑页预览（右侧小房间同步发光）。播放中变为 ⏸ Pause。
  7. 当前播放时间（红色竖线位置）。
  8. ↶ Undo / ↷ Redo　撤销 / 重做（最多 100 步）。
  9. Select all / Clear　选中全部行 / 取消选择。
  10. + Clip on selected rows　在选中的各行上添加片段（见 2.4）。
  11. Stagger　流水（追逐）效果，填写间隔毫秒数后点 Apply（见 2.5）。
  12. Copy / Paste / Duplicate　复制 / 粘贴 / 紧接原片段之后复制一份（见 2.2）。
  13. − + Fit　时间线缩小 / 放大 / 适应窗口。也可按住 Ctrl 滚动滚轮缩放。
  14. 时间尺。单击或拖动可移动红色播放线（playhead）。
  15. 墙名。点击选中整面墙的所有画框；点 ▾ 折叠 / 展开该墙。
  16. 画框行名。点击选中该行。右侧小数字为该画框已用步数（上限 24，见 2.7）。
  17. 片段。蓝 = Hold，绿 = Fade，橙 = Blink。片段上的文字：“0→100”表示由 0 渐变到 100，“100%”表示保持 100%。
  18. Room preview　房间预览，播放时各画框按播放线位置实时发光。
  19. 新增Cue list　勾选后该节目成为分段节目（见 2.8）。勾选后 Loop 自动关闭，工具栏出现 + Cue at playhead。

2.1 鼠标操作

操作方法
新建片段在某一行的空白处按住鼠标拖动，生成一个 Hold 片段。
移动片段左右拖动（只改变时间，不能换行；多选时一起移动）。
调整长度拖动片段的左边缘或右边缘。
选中片段单击。Shift 或 Ctrl + 单击可多选。
编辑片段参数先单击选中，再单击一次，弹出窗口（见 2.4）。
选中行单击行名；Shift + 单击选连续范围；Ctrl + 单击逐个加选；单击墙名选整面墙。
移动播放线单击时间尺，或在空白处单击。
缩放时间线Ctrl + 鼠标滚轮。
精确定位拖动时默认吸附到 100 ms 的整数倍；按住 Alt 可精确到 1 ms。

片段不能重叠。拖动到重叠位置时片段变红，松开后提示 “That would overlap another clip, so it was not applied”，操作不生效。

2.2 复制、粘贴与 Duplicate

按钮作用
Copy复制选中的片段。
Paste粘贴到播放线位置；粘贴前请先点时间尺移动播放线。
Duplicate紧接选中片段之后复制一份，可连续使用以依次排列。如果只选中了一个片段、同时选中了若干行，这些行也会各得到一份。

2.3 节目管理按钮（图 2-1 的 3）

按钮作用
New / Duplicate / Rename / Delete新建 / 复制 / 重命名 / 删除（删除前会确认；至少保留一个节目）。
Export将当前节目保存为一个文件（.json）。分段节目的分段点和段名一并保存。
Import从文件导入一个或多个节目，添加到列表中，不覆盖现有节目。
Export all将所有节目保存为一个文件，建议定期备份。

2.4 片段窗口

修改已有片段：单击选中后再单击一次。每项修改即时保存，窗口内显示 ✓ Saved；数值无效时以红字提示原因（如重叠、超出长度），且不会生效。

图 2-2　Edit clip
  1. Effect　Hold / Fade / Blink。
  2. Level %（Fade、Blink 时为 From %）　亮度 0–100。
  3. Start (s)　开始时间（秒）。
  4. Length (s)　持续时间（秒），可填小数。
  5. Delete　删除该片段（Done 关闭窗口）。

在多行上同时添加片段：先选中若干行，再点 + Clip on selected rows。

图 2-3　Add clip（以 Blink 为例）
  1. Effect　效果类型。
  2. From %　起始亮度。
  3. To %　目标亮度（Hold 无此项）。
  4. Period (ms)　闪烁周期，单位毫秒（仅 Blink）。
  5. Add　添加到所有选中的行。
  6. Cancel　取消。

2.5 流水效果（Stagger）

  1. 在需要参与流水的各行上建立相同的片段（可先选中这些行，用 + Clip on selected rows 一次添加）。
  2. 点时间尺，把播放线移到这些片段上（各行在播放线位置都必须有片段）。
  3. 选中这些行。
  4. 在 Stagger 后填入相邻画框的间隔（ms），点 Apply。

结果：选中的第一行保持不动，之后每一行依次比前一行晚一个间隔开始。图 2-1 的示例即为间隔 300 ms 的波浪。如提示 “Select 2+ rows that have a clip at the playhead”，请检查所选行数以及播放线位置。

2.6 循环节目

勾选 Loop 后出现 length ... ms，即循环一圈的总长度（如 8000 = 8 秒）。时间线上不能在该长度之外放置片段，且长度不能小于最后一个片段的结束时间。节目总长度显示在旁边的 Total。未循环的节目时间线最长 10 分钟，播放结束后各画框停在最后的亮度。

2.7 步数限制

每个画框最多 24 步。一个片段算一步，片段之间的空隙（熄灯）也算一步。

  • 行名右侧的小数字为已用步数。
  • 超过 24 步时该行变红，顶部显示 ⚠ N frames over 24 steps。
  • 超限的节目在 Run 模式下不能播放，会提示 “can't play: W1-3 needs 26 steps (max 24)”。请删减或合并片段后再播放。
  • 更新分段节目的 24 步限制按每一段分别计算（每个画框、每一段最多 24 步），整套时间线的总步数不受限制。行名右侧的数字为各段中最大的步数。

2.8 Cue list（分段节目）新增

适合由操作员根据演员提示逐段触发灯光的节目：时间线仍按普通节目制作，再用分段点把它切成若干段。播放时（见 4.4）每按一次 GO 播放下一段，各段之间灯光保持，直到下一次 GO。

图 2-4　分段节目的编辑（示例：3 段，分段点在 20 s 和 45 s）
  1. Cue list　勾选后该节目成为分段节目。取消勾选会清除分段点（可用 Undo 撤回）。
  2. + Cue at playhead　在播放线位置新建分段点。先单击时间尺移动播放线；播放线在 0 位置或已有分段点处不能新建。
  3. 橙色标签：各段的起点，显示“段号. 段名”，第 1 段从 0 开始。单击标签打开编辑窗口（图 2-5）。
  4. 第 2 段的分段点（20 s）。
  5. 第 3 段的分段点（45 s）。
  6. 段数提示。只有第 1 段时显示操作提示。
图 2-5　编辑分段点
  1. Name　段名，显示在 GO 按钮和段列表中；留空则显示 Section N。第 1 段只有段名可改。
  2. Starts at　该段的起始时间（秒），不能与其他分段点重复。
  3. Delete cue　删除该分段点，前后两段合并。
  4. Save　保存（Cancel 放弃）。
情况分段节目中的处理
片段之间及片段之前的空隙保持当前亮度，不熄灭（普通节目为熄灭）。需要熄灭时，放置一个 0% 的片段。
某一段中没有任何片段的画框该段不对这个画框做任何操作，画框保持原亮度。
跨越分段点的片段在分段点处自动拆开：Hold 保持不变；Fade 按比例拆成两段，亮度无跳变；Blink 若在周期中间被拆开，后一段先用 Fade 补完该周期，再接续 Blink，波形与原来一致。
步数每个画框每一段最多 24 步（见 2.7）。
预览编辑页的 ▶ Play 连续播放整条时间线，仅供预览。演出时只能按段 GO，整套时间线不能在灯上连续播放。

第 3 章　Programs 页 · 单框程序（Single frame）

点 Programs，再点 Single frame。这里制作只用于一个画框的程序，数量不限，每个程序最多 24 步，每次修改自动保存。修改后的程序会在下次于 Run 模式播放该画框时生效。

图 3-1　单框程序页（预览 Demo：亮 10 s → 闪 5 s → 熄灭）
  1. 程序列表。点击选中；名称下的 “used by N frames” 表示被 N 个画框使用。
  2. New（新建，默认 H100:1s）/ Duplicate / Rename / Delete。删除正在使用的程序时会提示，并使相关画框变为无程序。
  3. 当前程序名称。
  4. Loop　循环播放。
  5. 步数计数，如 3 / 24。
  6. + Add step　在末尾添加一步（满 24 步后不可用）。
  7. Type　Hold / Fade / Blink。
  8. Level (%)　亮度；Fade、Blink 时为起始亮度。
  9. To level (%)　目标亮度（Fade、Blink）。
  10. Blink period　闪烁周期：从 A 到 B 再回到 A 的时间（仅 Blink）。
  11. Duration　该步持续时间。
  12. 每行右侧按钮：↑ 上移、↓ 下移、✕ 删除该步。
  13. Program text　程序文本，与表格同步（见 3.2）。
  14. Level vs time　亮度–时间曲线。勾选 Loop 时显示两个周期，虚线为循环点；红线为预览播放位置。
  15. 预览方块，亮度越高越亮。
  16. ▶ Play / ■ Stop　预览播放 / 停止（播放中 Play 变为 ↻ Restart），并显示时间与亮度。未循环的程序播完后停在最后的亮度。离开本页预览自动停止。

3.1 时间的输入格式

Duration 与 Blink period 可输入：500ms、1.5s、10s；只输入数字时单位为毫秒。输入无效时输入框变红，并提示 Not a valid value。
最后一步的 Duration 填 0，表示执行该步后保持其亮度（例如 Hold、0%、0 = 最终保持熄灭）。

3.2 程序文本

表格下方的文本框与表格双向同步，也可直接编辑或复制粘贴。步骤之间用空格分隔。

写法含义
H100:10sHold：100%，持续 10 秒
F0-100:2sFade：2 秒内由 0 渐变到 100
B0-100/1s:5sBlink：0 与 100 之间来回，周期 1 秒，持续 5 秒
loop写在最前面，表示循环

示例：loop F0-100:2s F100-0:2s（2 秒变亮、2 秒变暗，循环）；H100:10s B0-100/1s:5s H0:0（亮 10 秒、闪 5 秒、熄灭）。
文本有误时，文本框下方以红字提示，表格保持不变；离开文本框时若仍有误，会恢复为最近一次正确的内容。

3.3 制作示例：亮 10 秒 → 闪 5 秒 → 熄灭

  1. 点 New，再点 Rename 命名。
  2. 第 1 步：Type = Hold，Level = 100，Duration = 10s。
  3. 点 + Add step。第 2 步：Type = Blink，Level = 0，To level = 100，Blink period = 1s，Duration = 5s。
  4. 再点 + Add step。第 3 步：Hold，Level = 0，Duration = 0。
  5. 点 ▶ Play 预览，并对照曲线图检查。

4.2 Run 模式：播放

图 4-3　Control 页（Run 模式）
  1. 节目下拉框，选择要播放的整套节目（只列出节目）。节目前带 ⚠ 表示超过步数限制，需先修改（见 2.7）；带 ⏭ 的是分段节目，选中后出现 Cue list 面板（见 4.4）。
  2. ▶ Play show　播放所选节目，所有画框同时开始。选中分段节目时此按钮隐藏，改用 GO（见 4.4）。
  3. ▶ Play all frames　每个画框播放它自己被分配的程序；未分配程序的画框不动。
  4. ■ Stop all　全部停止，保持当前亮度。
  5. All off　全部在 1 秒内渐灭至 0。
  6. 点击单个画框：播放该画框自己的程序，且该画框此后不再属于正在播放的节目。未分配程序时提示 “No program assigned”。

4.3 模拟器

图 4-4　模拟器打开、节目播放中
  1. Simulator ▸　再次点击关闭模拟器。
  2. 虚拟房间，直接读取灯光输出，亮度比左侧主画面更准确。

4.4 Cue list 播放（GO）新增

在节目下拉框选中带 ⏭ 的分段节目，图 4-3 上方出现 Cue list 面板。选中后软件会提前把前两段发送到各节点，下一段始终保持在准备好的状态，所以按下 GO 时只发送一个很小的指令，几乎没有延迟。

图 4-5　Cue list 面板（第 1 段播放中，下一段 Storm 已就绪）
  1. 节目下拉框，带 ⏭ 为分段节目。
  2. 段列表：当前段为蓝色，下一段为橙色边框，已播段变淡；段名后为该段时长。
  3. 状态行：当前段的播放时间。“next section ready ✓” 表示下一段已发送到全部节点；“preparing next section…” 表示仍在发送。
  4. GO ▶ 段名　播放下一段。也可按键盘 Space 或 Enter。最后一段之后显示 End of show，不可再按。
  5. ◀ Previous　重新播放上一段。需要重新发送该段，约 0.3–0.5 秒后开始。
  6. ↺ Replay section　从头重播当前段，立即开始。
  7. 段下拉框与 Go to　跳到任意一段。点 Go to 后需确认；该段可能需要重新发送，稍有延迟。
  8. Reset　回到第 1 段之前，需确认。灯保持原样，手动播放过的画框重新交回分段节目。
  9. 进度条：当前段的播放进度。
情况结果
当前段正在播放时按 GO当前段的所有画框停在当前亮度，下一段立即开始。下一段中没有片段的画框保持该亮度；有片段的画框从下一段的第一个片段开始，片段之前的空隙保持当前亮度。
当前段已播完、尚未收到提示灯保持最后一步的亮度，无论等多久，直到按 GO 才开始下一段。
连续快速按 GO300 ms 内的重复按键以及正在发送指令时的按键被忽略，不会跳过一段。
点击单个画框该画框播放自己的程序，并脱离分段节目，直到 Reset。状态行显示脱离的画框数。
刷新页面软件记住当前段号，状态行提示该段在刷新前已播放；下一次 GO 播放下一段，第一次可能需要重新发送。
无线通信中断灯保持当前状态，不会熄灭。恢复后可继续按 GO。
某段超过 24 步状态行显示红字，GO 不可用；请回到 Programs 页修改。
分段节目的各段是依次发送到节点的两个存储区（每个节点存两段）。因此 Previous 和跳转通常需要先重新发送，而 GO 与 Replay 不需要。

第 5 章　快捷键与备份

5.1 整套节目页快捷键

仅在整套节目页有效（输入文字或有弹窗时除外）。苹果电脑以 Cmd 代替 Ctrl。

按键作用
Space预览播放 / 暂停
Delete / Backspace删除选中的片段
Ctrl + C / Ctrl + V复制 / 粘贴（粘贴到播放线位置）
Ctrl + D紧接选中片段之后复制（可连续按）
Ctrl + Z撤销
Ctrl + Y / Ctrl + Shift + Z重做
Ctrl + A选中全部行
Esc取消选择
Ctrl + 滚轮缩放时间线
Alt + 拖动不吸附，精确到 1 ms
Space / Enter（Run 模式，Cue list 面板打开时）新增GO，播放下一段（输入文字或有弹窗时无效）

单框程序页没有快捷键，也没有撤销功能；修改较大的程序前，建议先用 Duplicate 保留一份副本。

5.2 备份与迁移

  • 整套节目：用 Export（单个）或 Export all（全部）导出为文件，在另一台电脑上用 Import 导入。分段节目的分段点和段名包含在导出文件中。
  • 单框程序及画框分配保存在浏览器中，没有导出功能；换电脑或换浏览器后需重新制作。
  • 如果浏览器禁止保存，启动时会提示 “This viewer blocks saving…”，此时请改用 Chrome 或 Edge 打开。
